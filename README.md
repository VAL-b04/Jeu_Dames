# Jeu de Dames

Un **Jeu de Dames** interactif en **Java**, programmé en **orienté objet** grâce à un ensemble de classes dédiées ainsi qu'une interface graphique faite avec **StdDraw**

---

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/VAL-b04/Jeu_Dames
cd Jeu_Dames

# Compiler tous les fichiers Java
javac -encoding UTF-8 StdDraw.java Gestionnaire_Interface.java Mouvement.java Position.java Pion.java Plateau.java Joueur.java Rafle.java Calculateur_Rafles.java Menu.java Jeu_Dames.java

# Lancer le jeu
java Jeu_Dames
```
